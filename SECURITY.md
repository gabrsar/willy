# Security Policy

Willy can handle OrcaSlicer profile data that may include printer IPs, tokens, API keys, or host credentials.

## Reporting Vulnerabilities

Please report sensitive security issues privately to:

`extremez3r0@gmail.com`

Include:

- affected Willy version
- operating system
- reproduction steps
- whether sensitive profile data could be exposed

## Supported Versions

Willy is currently pre-1.0. Security fixes target the latest `main` branch until release channels are established.

## Sensitive Data Rules

- Do not paste real OrcaSlicer API keys into issues.
- Prefer public/unknown repo mode unless the Git remote is private and trusted.
- Treat repositories created with private mode as permanently sensitive, including their Git history.
