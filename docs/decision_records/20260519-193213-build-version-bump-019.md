# Build Version Bump To 0.1.9

## Context

The Windows tray executable was rebuilt after folder picker changes, but the visible app version still showed `0.1.8` because the package metadata had not been bumped.

## Decision

Bump Willy from `0.1.8` to `0.1.9` and rebuild the Windows tray executable through `just build`.

## Consequences

- The settings window can verify that the newest build is running by showing `v0.1.9`.
- Version metadata remains synchronized between `pyproject.toml` and `src/willy/__init__.py`.
