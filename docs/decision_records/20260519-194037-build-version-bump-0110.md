# Build Version Bump To 0.1.10

## Context

The Windows tray and settings UI moved to PySide6 and the right-click menu was simplified. The visible application version needs to distinguish this build from the previous Tk-based `0.1.9` build.

## Decision

Bump Willy from `0.1.9` to `0.1.10` before rebuilding the Windows tray executable.

## Consequences

- The settings window can verify the PySide6 build by showing `v0.1.10`.
- Version metadata remains synchronized between `pyproject.toml` and `src/willy/__init__.py`.
